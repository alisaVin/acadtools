# :hammer_and_wrench: ACADTools: Plug-in für AutoCAD und ARES Commander


## :mag_right: Übersicht

Der ACADTools-Plugin ist ein Hilfsmittel, um die Zeichnungsinformationen für den Import nach FAMOS vorzubereiten. Es liest die Attribute und IDs von Raumpolygonen.
und Blockdefinitionen (bzw. Raumstempel) aus der gesamten DWG-Zeichnung aus und erstellt eine CSV-Tabelle, in der alle Importdaten eingetragen werden.
Die aktuelle Version ist für die Installation auf AutoCAD und ARES Commander 2021–2024 verfügbar.


## :computer: Anleitung zur Installation 

## AutoCAD

### Voraussetzungen

- AutoCAD (ab 2021)
- ACADTools.dll 
  *oder*
- ACADTools Bundle

### 1. AutoCAD mit der Zielzeichnung öffnen.
### 2. In die Befehlszeile den Befehl eingeben
	   > NETLOAD
### 3. Im Dialogfenster zum Plug-in Verzeichnis navigieren und ACADTools.dll auswählen
### 4. Beim Fenster "Sicherheit - unsignierte ausführbare Datei" bestätigen, dass das Plug-in immer geladen werden soll
